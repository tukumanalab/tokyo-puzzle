# 東京都 3D 市区町村パズル

東京都の市区町村（53地区）の地形を 3D プリントできるパズルです。国土地理院の標高データから生成した STL ファイルを配布しています。

🌐 **[https://tukumanalab.github.io/tokyo-puzzle/](https://tukumanalab.github.io/tokyo-puzzle/)**

## ピース仕様

- 全体スケール: 実距離 300km → 1.5mm（約 1/200,000）
- 高さ方向: 実寸比（Z_SCALE = 1.0）
- ベース厚さ: 3mm
- 東京全体: 約 448 × 228 mm

## 枠（フレーム）仕様

3 つのセクションをタブ/スロットで接続して一体の枠として使用できます。

| ファイル | 内容 | サイズ |
|---|---|---|
| `frame_tama_west.stl` | 多摩地区西部・西多摩郡 | 184 × 228 mm |
| `frame_tama_east.stl` | 多摩地区中部 | 125 × 228 mm |
| `frame_wards.stl` | 特別区（23区） | 148 × 228 mm |

- 総厚さ: 4mm
- ポケット深さ: 2mm（ピース受け面）
- 市区町村境界線: 0.5mm 盛り上がり

## データ生成フロー

```
npm run data:fetch   # 1. 行政界 GeoJSON をダウンロード
npm run data:stl     # 2. 市区町村ピース STL を生成
npm run data:frame   # 3. 枠 STL を生成
```

### 1. 行政界データの取得 (`scripts/fetch-boundaries.ts`)

国土交通省 国土数値情報（N03-2024）の東京都データを ZIP でダウンロードし、市区町村コードごとに GeoJSON ファイルとして保存します。

- 出力先: `public/data/boundary/{code}.json`
- 島嶼部（伊豆諸島・小笠原）は除外し、本土 53 地区のみ抽出
- 同一コードの複数ポリゴンは共有頂点でつながる本土側の連結成分のみを採用（飛び地除外）

### 2. ピース STL の生成 (`scripts/gen_stl.py`)

各市区町村の境界 GeoJSON と国土地理院の DEM（数値標高モデル）タイルから、3D メッシュを生成します。

#### 座標変換

地理座標（緯度経度）をミリメートル座標に変換します。

```python
PROJ_CENTER_LAT = 35.65
PROJ_CENTER_LON = 139.45
XY_SCALE = 1.5 / 300  # 1/200,000

x = (lon - 139.45) * cos(35.65°) * 111320 * XY_SCALE  # 東西
y = (lat - 35.65)  * 111320 * XY_SCALE                 # 南北
```

#### DEM タイルの取得

国土地理院の XYZ タイル（テキスト形式 DEM）を HTTP で取得します。

- URL: `https://cyberjapandata.gsi.go.jp/xyz/dem/{z}/{x}/{y}.txt`
- 標準ズームレベル: 13（約 10m 解像度）
- 大面積の市区町村（八王子市・奥多摩町など）はズーム 12（約 20m）に切り替え
- 取得したタイルはキャッシュ（`public/data/dem/`）に保存し再利用

#### メッシュ生成

1. 市区町村の bounding box を覆うタイルを結合してラスタ標高グリッドを構築
2. 境界ポリゴンをラスタライズし、市区町村外をマスク
3. グリッドを間引き（decimation）してポリゴン数を削減
4. 上面（地形面）・側面・底面を三角形メッシュに変換
5. 底面の裏側に市区町村名を浮き彫り

### 3. 枠 STL の生成 (`scripts/gen_frame.py`)

全 53 市区町村の輪郭を組み合わせたトレイ型の枠を生成します。

#### グローバルグリッド

全市区町村を単一のピクセルグリッド（0.5mm/px）に投影し、3 つのセクションをスライスして分割します。

```
[ tama_west ] | [ tama_east ] | [ wards ]
              ↑               ↑
          x = -53mm       x = +67mm
```

#### ラスタライズ

各セクションで **全 53 地区** のポリゴンをラスタライズします（担当地区以外も含む）。これにより、セクション境界をまたいで延びる市区町村の輪郭も正しくくり抜かれます。

- クリアランス: 0.3mm（`scipy.ndimage.binary_dilation` で拡張）
- 境界リッジ: 隣接する異なる市区町村のピクセルを検出し、床面から 0.5mm 盛り上げ

#### 断面構造

```
z=4mm ───┐    ┌──── 枠上面
         │    │
z=2.5mm  │  ┌─┘──── 境界リッジ
z=2mm ───┘  ╔╝───── ピース受け面
            ║
z=0mm ──────╚─────── 底面（フラット）
```

#### タブ/スロット接続

セクション間をタブ（雄）とスロット（雌）で嵌め合わせる構造です。

- タブ: 左セクション右端から 5mm 突出、高さ 15mm を繰り返し
- スロット: 右セクション左端をくり抜き（クリアランス 0.3mm）
- 配置行は両セクションともフレーム素材がある行に限定

## 開発環境

### 必要なツール

- Node.js 20+
- Python 3.x
- `pip install numpy Pillow scipy`

### セットアップ

```bash
npm install
npm run data:fetch   # 境界データ取得（初回のみ）
npm run data:stl     # ピース STL 生成（数十分かかります）
npm run data:frame   # 枠 STL 生成
npm run dev          # 開発サーバー起動
```

### CI/CD

`main` ブランチへの push で GitHub Actions が自動でデータ生成・ビルド・デプロイを実行します。スクリプトが変更されていない場合はキャッシュからデータを復元するため、2 回目以降は高速です。
